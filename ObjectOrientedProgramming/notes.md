# javascript and classes
- javascript is prototype based language, not class based like java or c++
- classes are syntactic sugar over prototypes, they provide a more familiar syntax for creating objects and handling inheritance, but they do not introduce a new object-oriented programming model to JavaScript.

## OOP
- It is programming paradigm , the style to write code, to structure code, to organize code.

## Object
- collection of properties and methods
- toLowerCase

## why use OOP
-  to avoid spaghetti code, to organize code, to reuse code, to create modular code, to create maintainable code, to create scalable code.
